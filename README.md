# Hit Machar — browser game recreation

A self-contained HTML/CSS/JavaScript mini-game inspired by the screenshots provided.
It uses original canvas-drawn artwork and code with the supplied face image included locally; it is not SankiBytes' original source code.

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser, or use VS Code Live Server.
3. Tap/click in the play area to aim and launch a swat shot.
4. Use the pause button to pause/resume.

No npm install or network assets required. Keep the `assets` folder beside `index.html`.
